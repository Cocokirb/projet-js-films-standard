# Gestionnaire de films

## Présentation

Ce projet est une application web permettant de gérer une collection de films.

## Fonctionnalités

- Ajouter un film avec son titre, son réalisateur, son année, sa durée et son genre
- Vérifier les informations saisies dans le formulaire
- Afficher plusieurs messages d'erreur simultanément pour chaque champs avec la raison de l'erreur
- Afficher les films enregistrés
- Supprimer un film individuellement
- Supprimer tous les films
- Réinitialiser le formulaire après un ajout réussi

## Lancement du projet

Pour lancer l'application, ouvrir le fichier `index.html` dans un navigateur récent.

Aucun serveur ni aucune installation n'est nécessaire.
